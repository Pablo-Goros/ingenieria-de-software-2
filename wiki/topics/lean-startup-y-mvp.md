# Lean Startup y MVP

## Overview

Lean Startup busca construir productos y negocios de modo eficiente validando ideas rápidamente con clientes y reduciendo el riesgo mediante iteración. Su ciclo central es Construir-Medir-Aprender. [OFF-008, pp. 2-3]

## How it works

Se formula una hipótesis, se construye un MVP o prototipo, se mide el comportamiento real y se aprende para decidir el próximo experimento o un pivote. El MVP contiene las características mínimas necesarias para probar una hipótesis, no una versión reducida construida sin propósito de aprendizaje. [OFF-008, pp. 3-5]

La medición debe usar métricas accionables y comparables; pueden emplearse experimentos A/B, cohortes, analítica, logging y embudos. [OFF-008, pp. 6-7]
