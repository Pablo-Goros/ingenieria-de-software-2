# Persistencia de datos

## Overview

El material externo agrupa archivos, prevalencia, bases de datos relacionales, escalamiento relacional y alternativas no relacionales bajo persistencia. [EXT-001]

## Core concepts

La elección del mecanismo de persistencia es una decisión arquitectónica ligada a las necesidades del sistema. No hay material oficial incorporado que desarrolle esta unidad, por lo que este tema debe tratarse como complementario. [EXT-001]
