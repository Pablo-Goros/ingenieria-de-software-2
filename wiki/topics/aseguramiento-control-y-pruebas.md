# Aseguramiento, control y pruebas

## Overview

El control de calidad (QC) se orienta al producto y detecta defectos existentes; el aseguramiento de calidad (QA) se orienta al proceso y busca prevenirlos durante todo el ciclo de vida. [OFF-010, pp. 15-18]

## Core concepts

Verificar comprueba que se construya correctamente conforme a requisitos; validar comprueba que el producto final satisfaga la necesidad del cliente. [OFF-010, p. 19] Las pruebas pueden clasificarse por nivel (unitarias, integración, sistema, aceptación), técnica (estáticas o dinámicas), alcance (funcionales o no funcionales) y automatización. [OFF-010, pp. 21-23]

Un caso de prueba debe vincularse con el requisito o historia correspondiente, declarar precondiciones, pasos, datos y resultados observables; Given-When-Then es un formato para expresar escenarios comprensibles por negocio, QA y desarrollo. [EXT-001]
