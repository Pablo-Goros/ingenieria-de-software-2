# Atributos de calidad

## Overview

Los atributos de calidad son dimensiones con las que se evalúa cómo un sistema satisface necesidades, más allá de las funcionalidades que ofrece. Se infieren a partir de requisitos no funcionales, operación del negocio, regulaciones y expectativas de usuarios. [OFF-001, pp. 7-8]

## Core concepts

No todos los atributos tienen el mismo peso: algunos resultan críticos para el éxito del sistema y pueden entrar en conflicto, por lo que requieren decisiones de diseño con trade-offs explícitos. [OFF-001, pp. 1, 7-8]
