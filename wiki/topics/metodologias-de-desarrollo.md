# Metodologías de desarrollo

## Overview

Una metodología reúne pasos del proceso y procedimientos de las actividades para desarrollar software. Incluye reglas, técnicas, herramientas, documentación y aspectos de formación. [OFF-002, p. 1]

## Core concepts

La elección depende, entre otros factores, del tamaño y complejidad del proyecto, las habilidades del equipo y la claridad y estabilidad de los requisitos. [OFF-007, p. 3]

Las metodologías estructuradas dividen el trabajo en fases secuenciales —análisis, diseño, implementación y pruebas—; facilitan la gestión y estimación, pero son poco flexibles ante cambios. [OFF-007, p. 5] En contraste, los enfoques iterativos e incrementales entregan valor y retroalimentación de manera repetida. [EXT-005]

RUP se presenta como un proceso iterativo e incremental. La diapositiva de metodologías enumera cuatro fases principales: inicio, elaboración, construcción y transición. [OFF-007, slide 9] El artículo que combina RUP con el modelo 4+1 describe flujos de trabajo y fases con iteraciones para probar y validar el diseño temprano, y añade una quinta etapa, evolución, que reinicia el ciclo para una nueva versión. [OFF-012, pp. 3-4] Se conserva esta diferencia entre las fuentes, sin asumir que ambas usan la misma lista de fases.

El mismo artículo combina RUP con el [modelo 4+1 de documentación de arquitectura](documentacion-de-arquitectura.md) para describir y validar una aplicación web. [OFF-012, pp. 5-9]
