# Calidad de software

## Overview

La gestión de calidad busca que los procesos de desarrollo cumplan estándares definidos y que el producto final satisfaga necesidades. No se limita a detectar errores: incluye prevención, satisfacción de usuarios, eficiencia y sostenibilidad. [OFF-010, p. 2]

## Core concepts

La calidad puede verse desde perspectivas trascendental, de usuario, fabricante, producto y valor. Estas visiones ayudan a establecer objetivos de prueba y expectativas explícitas. [OFF-010, pp. 3-8]

El costo de calidad corresponde a prevenir defectos; el de no calidad resulta de fallos internos o externos. Invertir preventivamente reduce el costo de no calidad. [OFF-010, p. 9]
