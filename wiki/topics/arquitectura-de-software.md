# Arquitectura de software

## Overview

Según el apunte externo, la arquitectura reúne las decisiones significativas de construcción de un sistema: elementos estructurales e interfaces, comportamiento y colaboración entre ellos, y el estilo arquitectónico que guía la organización. [EXT-001]

## Core concepts

El diseño parte de una necesidad del cliente y enfrenta restricciones de alcance, presupuesto, fecha, tecnología y regulación. Por ello, las decisiones arquitectónicas son trade-offs con impacto futuro. Este contenido proviene únicamente de material externo, no de los documentos oficiales incorporados. [EXT-001]
