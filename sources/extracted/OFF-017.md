Tipo de procesamiento Definición Ejemplo
Single Event Processing Procesa eventos de a uno, en forma
aislada.
Un sensor IoT de temperatura manda un evento y
el sistema dispara una alarma si pasa 30 °C.
Event Stream Processing
Procesa un flujo continuo de eventos,
aplicando transformaciones, agregaciones o
filtros en línea.
Analizando todos los clics en un sitio web para
métricas.
Complex Event Processing
Detecta patrones complejos a partir de
múltiples eventos simples, correlacionados
en tiempo y espacio.
En un sistema financiero: detectar fraude
combinando patrón de muchos retiros pequeños +
acceso desde IP inusual.
Online Event Processing
Procesa eventos en tiempo real, casi sin
latencia, para reaccionar inmediatamente al
suceso.
Registrar en tiempo real el clic de un usuario en un
e-commerce y actualizar su carrito.
